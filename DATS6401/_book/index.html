Welcome

This is the course book for DATS 6401 — Visualization of Complex Data, a graduate course at the George Washington University.

The course is organized around data modalities — the idea that “complex data” comes in distinct shapes (tabular, time-series, networks, text, images, geographic), each with its own visualization challenges. It is delivered through Streamlit, and builds toward a full client–server machine-learning application in which an interactive front-end communicates with a model served behind an API.

How this book works

Each chapter corresponds to one two-hour class session that interleaves concept lecture with hands-on work. Within a chapter you’ll find background and motivation, learning objectives, readings, a session outline with timings, code, an in-class activity, and homework.

A note on the code in this book:

  • In the Foundations chapters (Weeks 1–4), the Python code is executable — the charts you see were generated by running the code on this page. You can copy it and run it yourself; it uses datasets that ship with the libraries, so nothing needs to be downloaded.
  • From Week 5 onward, much of the code builds Streamlit apps and FastAPI/Flask servers. That code cannot run inside a static web page (a Streamlit app is a running server, not a chart). It is shown as copy-and-run source for your own environment, and where an app has been deployed, the live app is embedded directly in the page.

Course arc

  • Weeks 1–4 — Foundations. Setup, the grammar of graphics and perception, then the two conventional modalities (tabular/multivariate with PCA, and time-series with uncertainty).
  • Week 5 — The hinge: Streamlit. Everything after this is delivered as an app.
  • Weeks 6–10 — Complex modalities. Networks, text, images, and the two-part map module.
  • Weeks 11–13 — The client–server arc. Consume an endpoint → serve a model (FastAPI/Flask) → visualize live ML/NLP output.
  • Week 14 — Deploy, reflect, ship. Deploy the full system, confront visualization ethics, and workshop the final project.

Projects

  • Mid-Semester Project (20%) — a multi-modality visualization Streamlit app.
  • Final Project (40%) — a deployed client–server ML application: a FastAPI/Flask model endpoint with a Streamlit client that visualizes its output.
