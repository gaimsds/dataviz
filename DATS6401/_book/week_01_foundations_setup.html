Week 1 — Foundations & Setup

What makes data “complex,” and how we will work with it this semester. This chapter sets up the environment, the workflow, and the conceptual frame for the whole course, ending with a first look at Streamlit.

📖 Background & Motivation

Data visualization in a graduate data-science context is more than making charts — it is the craft of turning data of many shapes into understanding. This course is organized around the idea that “complex data” comes in distinct modalities: tabular tables, time series, networks, text, images, and geographic data. Each has its own structure, its own failure modes, and its own visual vocabulary. Before we can visualize any of them well, we need a shared foundation: a reliable Python environment, the habit of working with tidy data, and a clear sense of what good visualization is for.

This week also introduces the tool that distinguishes this course from a notebook-only workflow: Streamlit. Rather than ending each project as a static rendered document, you will increasingly build small interactive applications. We start gently — a “hello world” app — so that the tool is familiar long before the client–server work later in the term.

🔎 Learning Objectives

  • Set up a reproducible Python environment for visualization and app development.
  • Articulate what “complex data” means and identify the modalities covered in this course.
  • Load and inspect a dataset with pandas and produce a first chart.
  • Launch and edit a minimal Streamlit application.

📚 Readings & Resources

  • Wilke, Fundamentals of Data Visualization, Ch. 1–2 — what visualization is for.
  • Streamlit — Get Started — installing and running your first app.
  • Tidy Data by Hadley Wickham — the data-shape standard we rely on all term.
  • pandas — 10 minutes to pandas — quick refresher.

🛠️ Setup Checklist

Make sure your environment includes:

pip install pandas numpy matplotlib seaborn altair plotly streamlit

Create and activate a virtual environment, confirm the imports work, and verify you can run streamlit hello before class.

🧭 Two-Hour Session Outline

Single 2-hour block. The first meeting is lighter on hands-on and heavier on orientation, but we still end with everyone running code.

Block 1 — Concepts & Theory (~35 min, PowerPoint). Course overview and modality-driven structure (10) · what makes data “complex” (10) · the workflow: tidy data, reproducibility, notebooks vs. apps (10) · discussion: good vs. bad charts (5).

Block 2 — Guided Demonstration (~30 min). Environment check + load a dataset (10) · first chart and the anatomy of a figure (10) · a two-line Streamlit app (10).

☕ Break (~10 min).

Block 3 — Hands-On (~30 min). Get the environment running and load a dataset (10) · produce one chart and drop it into a minimal Streamlit app (20).

Block 4 — Wrap-Up (~10 min). Troubleshooting round-up (5) · preview homework and the data-sources page (5).

import matplotlib.pyplot as plt

fig, ax = plt.subplots()

ax.set_xlabel("Total bill ($)")
ax.set_ylabel("Tip ($)")
ax.set_title("Tips vs. total bill")
plt.show()

The same idea as a Streamlit app (copy-and-run)

This is not executed here — a Streamlit app is a running server, not a chart. Save it as app.py and run streamlit run app.py in your own environment.

# app.py  —  run with:  streamlit run app.py
import streamlit as st
import plotly.express as px

st.title("My First App")
df = px.data.tips()
st.dataframe(df)
st.scatter_chart(df, x="total_bill", y="tip")

🏠 Homework

  1. Set up your environment and confirm all libraries import.
  2. Pick a dataset from the sample sources or bring your own.
  3. Build a small Streamlit app that loads the data, shows a preview, and renders one chart.
  4. Add a short text panel describing the dataset and what your chart shows.
  5. Submit the runnable app (and any data) to Blackboard.

Rubric (10 pts): working environment and runnable app (4) · a correct, labeled chart (3) · clear description of the data and chart (3).

🧩 Optional Extensions

  • Add a Streamlit widget (a selectbox of columns) that changes the chart.
  • Compare matplotlib and Altair for the same chart.
  • Explore the data-sources page and bookmark candidates for your mid-term project.

✅ Submission Checklist

  • Your description and chart are clearly displayed in the app.
