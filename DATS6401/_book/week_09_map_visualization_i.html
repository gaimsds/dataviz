Week 9 — Map Visualization — Module I

Putting data on the Earth, correctly. The first of two map modules covers the foundations: coordinate reference systems, projections, spatial joins, and static thematic maps with the Python geospatial stack.

📖 Background & Motivation

Geographic data is special because location is both the key and a source of distortion. The Earth is a sphere; a map is flat; every projection that flattens it lies in some way — about area, shape, distance, or direction. A choropleth that looks authoritative can mislead badly if it ignores projection, uses raw counts where rates are needed, or bins values carelessly. So before any pretty map, this module establishes the unglamorous foundations: coordinate reference systems (CRS), projections and what each preserves, and spatial joins that attach data to geometry.

We then build the core static thematic maps — choropleths, dot-density, and hex/bin maps — with geopandas, mapclassify, and contextily. The emphasis is on honesty: choosing rates over counts, classifying values defensibly, and picking projections suited to the question. This grounding sets up Module II next week, where the same data becomes interactive and lands inside a Streamlit dashboard.

🔎 Learning Objectives

  • Explain CRS and projections, and choose an appropriate projection for a task.
  • Perform spatial joins to attach tabular data to geometry.
  • Build choropleth, dot-density, and hex/bin maps with the Python geospatial stack.
  • Normalize correctly (rates vs. counts) and classify values defensibly.

📚 Readings & Resources

  • GeoPandas — user guide.
  • “The problem with choropleth maps” — counts vs. rates.
  • mapclassify — classification schemes.
  • A gentle intro to projections — what each preserves.

Sample Data Sources for Practice:

  • US Census / TIGER shapefiles.
  • Natural Earth — country/region geometry.
  • GeoPandas built-in datasets.

🛠️ Setup Checklist

Make sure your environment includes:

pip install geopandas mapclassify contextily matplotlib pandas streamlit

GeoPandas can be finicky to install — confirm import geopandas works in your environment before class.

🧭 Two-Hour Session Outline

Single 2-hour block.

Block 1 — Concepts & Theory (~30 min, PowerPoint)

  1. CRS and projections: why flat maps distort (10 min)
  2. Spatial joins: attaching data to geometry (8 min)
  3. Choropleths done right: rates, classification, color (10 min)
  4. Discussion: a famous misleading map (2 min)

Block 2 — Guided Demonstration (~30 min, live coding)

  1. Load geometry, set/reproject CRS (8 min)
  2. Spatial-join attribute data; build a choropleth with a classification scheme (15 min)
  3. Add a basemap with contextily (7 min)

☕ Break (~10 min)

Block 3 — Hands-On Activity (~40 min, students working)

  1. Students load geometry + data and reproject correctly (10 min)
  2. Build a rate-based choropleth with a defensible classification (20 min)
  3. Save the figure into a simple Streamlit display app (10 min)

Block 4 — Wrap-Up & Homework Preview (~10 min)

  1. Compare choropleths using counts vs. rates — the story changes (6 min)
  2. Preview homework and Module II (4 min)

💻 Notebook / App Snippets

Load, reproject, inspect

import geopandas as gpd
gdf = gpd.read_file("regions.geojson")
print(gdf.crs)
gdf = gdf.to_crs(epsg=5070)   # an equal-area projection for the US

Spatial join + choropleth

import matplotlib.pyplot as plt
joined = gdf.merge(data, on="region_id")
joined["rate"] = joined["cases"] / joined["population"] * 100_000

joined.plot(column="rate", scheme="quantiles", k=5,
            cmap="OrRd", legend=True, edgecolor="white", linewidth=0.3)
plt.axis("off")

Basemap

import contextily as cx
ax = joined.to_crs(epsg=3857).plot(column="rate", cmap="OrRd", alpha=0.7)
cx.add_basemap(ax)

🧪 In-Class Activity

  • Build the same choropleth twice: once with raw counts, once with a rate.
  • Discuss:

How does normalization change which regions stand out?

Which classification scheme (quantiles, equal-interval, natural breaks) is most honest here?

Does your projection preserve area? Should it, for this map?

Hints

# For comparing regions by intensity, almost always map a RATE, not a count

🏠 Homework

  1. Choose a dataset with a geographic key (region/state/county).
  2. Build a rate-based choropleth with an appropriate projection and classification.
  3. Write a short note justifying your projection, normalization, and classification choices.
  4. Submit as a Streamlit app or .ipynb + .html.

Rubric (10 pts)

  • Correct CRS/projection and spatial join (3)
  • Rate-based, well-classified choropleth (4)
  • Justification of cartographic choices (3)

🧩 Optional Extensions

  • Add a dot-density or hex-bin alternative and compare.
  • Try two projections and discuss the trade-off.
  • Add a basemap and adjust opacity for legibility.

✅ Submission Checklist

Before submitting, make sure:

  • Your assignment fulfills all the basic requirements listed above.

  • Any Streamlit app runs locally with no errors.

  • You map a rate (not a raw count) and justify your projection.
