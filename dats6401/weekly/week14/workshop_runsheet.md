# Block 3 Workshop Runsheet (~50 min)

## Format
Groups of 4 (3 if needed). Each member: 2-3 min demo + 4 min critique. ~28 min of
rotations + 10 min cross-group highlights + 5 min buffer. Keep time STRICTLY —
a visible timer helps.

## Per rotation
1. Presenter demos the LIVE deployed app (localhost only if deployment blocked —
   note it as their #1 action item).
2. Reviewers fill critique_sheet.md silently during the demo.
3. 4 min discussion: works -> unclear -> suggestion, each reviewer in turn.
4. Sheets go to the presenter.

## Instructor circulation priorities
- Flag any demo running on localhost: deployment is due with the project.
- Listen for lens 1 (honesty) issues — surface the best catch to the whole room.
- Note 2-3 strong examples for the Block 4 wrap-up.

## Block 4 wrap (~10 min)
- 2-3 highlighted catches (anonymized if kind).
- The deadline logistics: April 30, deployed URLs + repo + README, defense slots.
- Final words: office hours through finals week; bring blockers EARLY.
