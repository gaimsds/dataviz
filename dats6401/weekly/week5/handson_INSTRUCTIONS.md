# Week 5 — Block 3 Hands-On (~45 min)

**Goal:** convert one of YOUR notebooks from Weeks 2–4 into a deployed Streamlit app.

## Steps
1. (~25 min) Pick an analysis you built in Weeks 2–4 (encodings chart, PCA scatter,
   time-series trend). Create `app.py` and port it: data load -> widgets -> chart.
   Don't have one handy? Use `starter_template.py` in this folder as scaffolding.
2. (~10 min) Add at least: a sidebar, TWO widgets that change the output,
   and one layout element (columns or tabs). Wrap the data load in `@st.cache_data`.
3. (~10 min) Deploy: push to a GitHub repo -> share.streamlit.io -> New app.
   Paste your live URL in the class thread.

## Checklist before you leave
- [ ] `streamlit run app.py` works locally with no errors
- [ ] Two widgets, one layout element, caching applied
- [ ] Deployed URL loads for your neighbor

A completed reference (`example_solution.py`, a Week-3 PCA explorer) is for AFTER you try.
